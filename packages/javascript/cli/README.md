# @lumis-sh/cli

Run the Lumis command line syntax highlighter with npm or npx.

```sh
npx @lumis-sh/cli --help
```

```sh
npm install -g @lumis-sh/cli
lumis --help
```

The package downloads the matching prebuilt `lumis` binary from the `cargo-lumis-cli/v<version>` GitHub release during installation.
