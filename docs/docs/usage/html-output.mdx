# HTML Output Structure

All HTML formatters produce the same DOM structure:

```html
<pre class="lumis" style="...">
  <code class="language-rust" translate="no" tabindex="0">
    <div class="line" data-line="1">
      <span style="color: #e5c07b;">fn</span> <span style="color: #61afef;">main</span>
    </div>
    <div class="line" data-line="2">
      ...
    </div>
  </code>
</pre>
```

## Elements

| Element | Purpose |
| --- | --- |
| `<pre class="lumis">` | Outer wrapper. Background color is set here (inline or via CSS). |
| `<code class="language-*">` | Language identifier. `translate="no"` prevents browser auto-translation. `tabindex="0"` makes the block keyboard-focusable. |
| `<div class="line" data-line="N">` | One per line. `data-line` is 1-indexed. Useful for line numbers, DOM hooks, and custom styling. |
| `<span>` | One per token. Carries inline styles, CSS classes, or CSS variables depending on the formatter. |

## `preClass` option

Add custom CSS classes to the `<pre>` tag. Produces `<pre class="lumis code-block my-custom" style="...">`.

<Tabs groupId="runtime" queryString="lang" defaultValue="javascript">
  <TabItem value="javascript" label="JavaScript">

```js
const html = await highlight(
  'fn main() {}',
  htmlInline({language: rust, theme: dracula, preClass: 'code-block my-custom'})
)
```

  </TabItem>
  <TabItem value="rust" label="Rust">

```rust
let formatter = HtmlInlineBuilder::new()
    .lang(Language::Rust)
    .theme(Some(themes::get("dracula").unwrap()))
    .pre_class(Some("code-block my-custom".to_string()))
    .build()
    .unwrap();
```

  </TabItem>
  <TabItem value="elixir" label="Elixir">

```elixir
Lumis.highlight!(
  "fn main() {}",
  language: "rust",
  formatter: {:html_inline, theme: "dracula", pre_class: "code-block my-custom"}
)
```

  </TabItem>
</Tabs>

## `header` option

Wrap the entire block with custom HTML:

<Tabs groupId="runtime" queryString="lang" defaultValue="javascript">
  <TabItem value="javascript" label="JavaScript">

```js
const html = await highlight(
  'fn main() {}',
  htmlInline({
    language: rust,
    theme: dracula,
    header: {openTag: '<figure><figcaption>main.rs</figcaption>', closeTag: '</figure>'},
  })
)
```

  </TabItem>
  <TabItem value="rust" label="Rust">

```rust
use lumis::formatter::HtmlElement;

let formatter = HtmlInlineBuilder::new()
    .lang(Language::Rust)
    .theme(Some(themes::get("dracula").unwrap()))
    .header(Some(HtmlElement {
        open_tag: "<figure><figcaption>main.rs</figcaption>".to_string(),
        close_tag: "</figure>".to_string(),
    }))
    .build()
    .unwrap();
```

  </TabItem>
  <TabItem value="elixir" label="Elixir">

```elixir
Lumis.highlight!(
  "fn main() {}",
  language: "rust",
  formatter: {:html_inline,
    theme: "dracula",
    header: %{open_tag: "<figure><figcaption>main.rs</figcaption>", close_tag: "</figure>"}
  }
)
```

  </TabItem>
</Tabs>

Produces:

```html
<figure>
  <figcaption>main.rs</figcaption>
  <pre class="lumis" style="...">...</pre>
</figure>
```

## `includeHighlights` option

When set to `true`, each token `<span>` gets a `data-highlight` attribute with the Tree-sitter scope name:

```html
<span style="color: #e5c07b;" data-highlight="keyword">fn</span>
```

<Tabs groupId="runtime" queryString="lang" defaultValue="javascript">
  <TabItem value="javascript" label="JavaScript">

```js
const html = await highlight(
  'fn main() {}',
  htmlInline({language: rust, theme: dracula, includeHighlights: true})
)
```

  </TabItem>
  <TabItem value="rust" label="Rust">

```rust
let formatter = HtmlInlineBuilder::new()
    .lang(Language::Rust)
    .theme(Some(themes::get("dracula").unwrap()))
    .include_highlights(true)
    .build()
    .unwrap();
```

  </TabItem>
  <TabItem value="elixir" label="Elixir">

```elixir
Lumis.highlight!(
  "fn main() {}",
  language: "rust",
  formatter: {:html_inline, theme: "dracula", include_highlights: true}
)
```

  </TabItem>
</Tabs>

Useful for debugging theme mappings or building custom JS on top of the highlighted output.

## Differences between formatters

| Formatter | `<span>` carries |
| --- | --- |
| HTML inline | `style="color: ...; ..."` |
| HTML linked | `class="keyword"` (semantic class names) |
| HTML multi-themes | `style="--lumis-light: ...; --lumis-dark: ...; color: var(--lumis-light);"` |
