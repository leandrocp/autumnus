# Next.js

[Full example on GitHub](https://github.com/leandrocp/lumis/tree/main/examples/nextjs)

Next.js MDX already supports `rehypePlugins`. That makes `@lumis-sh/rehype-lumis` the right Lumis integration point.

## Install

```bash
npm install @next/mdx @mdx-js/loader @mdx-js/react @types/mdx
npm install @lumis-sh/rehype-lumis @lumis-sh/themes
```

## Configure `next.config.mjs`

Pass the plugin as a string so Turbopack can resolve it:

```js
import createMDX from '@next/mdx'
import githubLight from '@lumis-sh/themes/github_light'

const withMDX = createMDX({
  options: {
    rehypePlugins: [
      ['@lumis-sh/rehype-lumis', {
        theme: githubLight,
        fallbackLanguage: 'plaintext',
      }],
    ],
  },
})

export default withMDX({
  pageExtensions: ['js', 'jsx', 'md', 'mdx', 'ts', 'tsx'],
})
```

The plugin name is passed as a string (`'@lumis-sh/rehype-lumis'`) instead of a function reference because Next.js Turbopack requires serializable options. The theme object is plain JSON, so it serializes fine.

You also need `app/layout.tsx` and `mdx-components.tsx` at the project root for Next.js App Router MDX to work.
