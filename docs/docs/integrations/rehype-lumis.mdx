# rehype-lumis

[Full example on GitHub](https://github.com/leandrocp/lumis/tree/main/examples/rehype-lumis)

Use `@lumis-sh/rehype-lumis` when your stack already has a rehype stage.

## Install

```bash
npm install @lumis-sh/rehype-lumis @lumis-sh/themes
```

## Example

```ts
import rehypeLumis from '@lumis-sh/rehype-lumis'
import githubLight from '@lumis-sh/themes/github_light'

processor.use(rehypeLumis, {
  theme: githubLight,
  fallbackLanguage: 'plaintext',
})
```

This plugin replaces `pre > code` blocks in HAST with Lumis HTML output.

## Full pipeline

```ts
import {unified} from 'unified'
import remarkParse from 'remark-parse'
import remarkRehype from 'remark-rehype'
import rehypeStringify from 'rehype-stringify'
import rehypeLumis from '@lumis-sh/rehype-lumis'
import githubLight from '@lumis-sh/themes/github_light'

const file = await unified()
  .use(remarkParse)
  .use(remarkRehype)
  .use(rehypeLumis, {
    theme: githubLight,
    fallbackLanguage: 'plaintext',
  })
  .use(rehypeStringify)
  .process(markdown)
```

## Options

- `theme` - required Lumis theme
- `langs` - extra language definitions passed to `createHighlighter`
- `loadLanguages` - languages to preload during setup
- `defaultLanguage` - used when the code block has no `language-*` class and `detectLanguage` is false
- `fallbackLanguage` - used when the requested language fails
- `preClass` - class added to the generated `<pre>`
- `detectLanguage` - passes `undefined` language to Lumis instead of using `defaultLanguage`
- `includeHighlights` - enables highlight metadata in HTML output
- `italic` - keeps italic token styles in output
- `onError` - error hook with `{ language, code }`

## Behavior

- visits `pre > code` blocks in HAST
- reads languages from `language-*` classes on the `<code>` or `<pre>` node, or from `data-language` / `language` properties
- replaces each block with Lumis HTML output
- loads languages asynchronously and loads requested fence languages before rendering

Use it in:

- `unified`
- MDX pipelines
- Next.js MDX
- Astro markdown and MDX
- `react-markdown`
