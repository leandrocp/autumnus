# Auto-detect language

<Tabs groupId="runtime" queryString="lang" defaultValue="javascript">
  <TabItem value="javascript" label="JavaScript">

```js
const html = await highlight('#!/usr/bin/env bash\necho "hello"', htmlInline({theme: dracula}))
```

  </TabItem>
  <TabItem value="rust" label="Rust">

```rust
use lumis::languages::Language;

let lang = Language::guess(Some("script.sh"), source);
```

  </TabItem>
  <TabItem value="elixir" label="Elixir">

```elixir
Lumis.highlight!("#!/usr/bin/env bash\necho 'hello'")
```

  </TabItem>
  <TabItem value="cli" label="CLI">

```bash
lumis highlight main.rs
```
