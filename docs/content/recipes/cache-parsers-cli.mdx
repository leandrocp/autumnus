Parser warm-up is a common operation across Lumis runtimes. See
[Warm up parsers](/operations/warm-up) for application lifecycle APIs, the CLI
command, `LUMIS_DATA_DIR`, Elixir configuration, and the runtimes that do not
need a parser cache.
