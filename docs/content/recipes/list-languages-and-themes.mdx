import { Tabs, Tab } from 'fumadocs-ui/components/tabs';


A language is the same record everywhere, sorted by id: `id`, `name`,
`aliases`, `extensions`, `globs`, `emacsModes` and `shebangs`.

`themes.available()` and `Lumis.Theme.available/0` return theme names and
appearances. Rust's `themes::available()` returns complete themes. Use
`themes.get(name)`, `themes::get(name)`, or `Lumis.Theme.get/1` to look up one theme.

<Tabs groupId="runtime" persist items={['JavaScript / TypeScript', 'Rust', 'Elixir', 'CLI']}>
  <Tab value="JavaScript / TypeScript">

```js
import * as languages from '@lumis-sh/lumis/languages';
import * as themes from '@lumis-sh/lumis/themes';

for (const language of languages.available()) {
  const {id, name, extensions} = language
  console.log(id, name, extensions)
}

for (const theme of themes.available()) {
  console.log(theme.name, theme.appearance)
}
```

  </Tab>
  <Tab value="Rust">

```rust
use lumis::{languages, themes};

for language in languages::available() {
    println!(
        "{} {} {:?}",
        language.id, language.name, language.extensions
    );
}

for theme in themes::available() {
    println!("{} {:?}", theme.name, theme.appearance);
}
```

  </Tab>
  <Tab value="Elixir">

```elixir
for language <- Lumis.Languages.available() do
  IO.inspect(
    {language.id, language.name, language.extensions}
  )
end

for theme <- Lumis.Theme.available() do
  IO.inspect({theme.name, theme.appearance})
end
```

  </Tab>
  <Tab value="CLI">

```bash
lumis languages list
lumis themes list
```

  </Tab>
</Tabs>

## Look one up by name

Aliases resolve the way highlighting resolves them, so `js` finds JavaScript.

How an unknown name is reported follows each host's convention: JavaScript / TypeScript
returns `undefined` and Elixir returns `nil`, both without raising, while Rust
returns `None` for an unknown language and an error for an unknown theme. The CLI exits non-zero.

<Tabs groupId="runtime" persist items={['JavaScript / TypeScript', 'Rust', 'Elixir', 'CLI']}>
  <Tab value="JavaScript / TypeScript">

```js
import * as languages from '@lumis-sh/lumis/languages';
import * as themes from '@lumis-sh/lumis/themes';

// { id: 'javascript', name: 'JavaScript', ... }
languages.get('js')
languages.get('nope')  // undefined

themes.get('catppuccin_frappe')
```

If you know the theme name ahead of time, an individual import keeps the rest of the catalog out of
your bundle:

```js
import frappe from '@lumis-sh/themes/catppuccin_frappe'
```

  </Tab>
  <Tab value="Rust">

```rust
use lumis::{languages, themes};

if let Some(language) = languages::get("js") {
    println!("{:?}", language.extensions);
}

let theme = themes::get("catppuccin_frappe")?;
println!("{} {}", theme.name, theme.appearance);
```

  </Tab>
  <Tab value="Elixir">

```elixir
Lumis.Languages.get("js")
# %{id: "javascript", name: "JavaScript", ...}

Lumis.Languages.get("nope")
# nil

Lumis.Theme.get("catppuccin_frappe")

# %Lumis.Theme{name: "catppuccin_frappe",
#   appearance: "dark", ...}
```

  </Tab>
  <Tab value="CLI">

```bash
lumis languages show js
lumis themes show catppuccin_frappe
```

  </Tab>
</Tabs>

## What is loaded right now

The catalog lists what Lumis knows about. This lists what can be highlighted
without a download, which is a smaller set — highlighting loads what a document
turns out to need.

Themes have no equivalent: every theme is compiled in, so there is nothing to
load and nothing that could be missing.

<Tabs groupId="runtime" persist items={['JavaScript / TypeScript', 'Rust', 'Elixir', 'CLI']}>
  <Tab value="JavaScript / TypeScript">

```js
import * as languages from '@lumis-sh/lumis/languages';

languages.loaded() // ['json', 'rust']
```

  </Tab>
  <Tab value="Rust">

Languages are compiled in behind `lang-*` features, so everything in
`languages::available()` is ready to use.

  </Tab>
  <Tab value="Elixir">

```elixir
Lumis.Languages.load("elixir")
Lumis.Languages.loaded()
# ["elixir"]
```

Loading is global to the VM, so this is the same list in every process.

  </Tab>
  <Tab value="CLI">

There is nothing to list. Each invocation is a fresh process that loads what
the document needs and exits, so nothing stays loaded between runs.

What does persist is the parser cache on disk, which `lumis languages download`
fills so later runs skip the download:

```bash
lumis languages download rust javascript
```

  </Tab>
</Tabs>
